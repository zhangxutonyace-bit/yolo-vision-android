## 设备自动测试

- OnDeviceModelTest：七个内置模型，官方公交车图，实际 Android CPU 推理。
- RealCameraSmokeTest：真实 CameraX 新帧、暂停 JPEG、继续后的新帧。
- SettingsFlowTest：操作可见设置控件，验证 Activity 重建后开关状态。
- RealCameraLifecycleTest：前后镜头及新推理、暂停快照跨 Activity 重建、明确继续，以及 CREATED → RESUMED 生命周期恢复。

本次共 4 个测试方法通过，分两次完整结果 OK (3 tests) 与 OK (1 test)。七模型检查包含在第一个方法内，不另外计为 7 个 JUnit 测试。Activity 重建与生命周期转换不替代真实横竖屏排版、前置镜像或锁屏验收。

连接已获准调试的测试手机后，可执行 gradlew.bat :app:connectedDebugAndroidTest。这会安装应用与临时测试组件并启动相机；不要与人工手机操作同时进行。先确认同名应用与签名，避免为解决安装冲突而卸载用户数据。

设置和相机测试用 DeviceTestSupport.preservingPreferences 备份偏好，在 finally 恢复；本次日志确认恢复 7 个键。测试也会生成本机模型与图片缓存。测试结束须核实任务与设置，卸载临时组件，保留主应用，并按用户需要关闭临时调试连接。
