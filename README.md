# YOLO 视觉 · 中文安卓体验版

简洁中文界面的原生 Android App，基于 CameraX 与 LiteRT 在手机本地运行 YOLO 模型。主界面保留任务切换、相机画面、暂停、切换镜头和分享；模型与高级参数集中在设置面板。

版本：0.1.0。应用标识：`cn.local.yolovision`。最低 Android 8.0（API 26）。这是独立开发的体验版，并非 Ultralytics 官方 App。

## 已实现

- 相机实时识别，青色识别框，常见目标中文标签。
- 七种任务：目标检测、实例分割、语义分割、深度估计、图像分类、人体姿态、旋转框检测。
- 内置七个 YOLO26 nano 模型（共 21.70 MiB），首次使用无需下载模型。相机画面在本机处理。
- 模型选择面板：每种任务均提供 n / s / m / l / x 五种规格，较大规格按用户选择从官方发布下载，校验文件大小和 SHA-256 后使用。
- 高级设置：适用任务的置信度与 IoU、置信度显示、性能显示、硬件加速、恢复默认设置。默认隐藏置信度及性能信息。
- 前后镜头切换、设备实际提供的镜头倍率、支持时开启补光。
- 暂停、恢复识别；暂停画面和识别结果配对保存，旋转屏幕后可恢复暂停画面。
- 调用 Android 系统分享面板分享识别图；由用户选择接收应用与发送操作。
- 相机权限引导、下载取消、加载失败重试、硬件加速不支持时回退到 CPU。

分类模型的部分标签保留原文；语义图、深度图及骨骼使用各自可视化形式，不是所有任务都产生检测框。深度结果用于相对远近观察。暂停与分享导出的是推理帧，非相机全分辨率照片。

Android 模型输出需要客户端执行 NMS，因此检测、实例分割、姿态和旋转框任务的 IoU 设置有效。界面在这些任务启用 IoU，其他任务隐藏不适用参数。

## 安装和使用

1. 按[构建说明](docs/BUILD.md)生成 `app/build/outputs/apk/debug/app-debug.apk`，或使用 Android Studio 直接安装。
2. 从手机文件管理器打开 APK，按系统提示允许该文件管理器安装应用。
3. 打开 **YOLO 视觉**，点击“开启相机”，允许相机权限。
4. 首次会载入内置目标检测模型，对准人物、车辆、椅子等常见物体即可观察结果。
5. 左上任务按钮切换识别类型；右上齿轮进入模型与高级设置。
6. 底部蓝色按钮暂停／继续，右侧分享当前识别图。

如模型无法载入，进入设置关闭“优先硬件加速”后重试。速度和支持的镜头取决于手机。可选模型下载需要连接 GitHub；网络不可达时仍可使用内置轻量模型。

仓库提供完整源码与模型，不包含预编译 APK 或签名私钥。当前构建配置使用开发测试签名，适合安装体验；应用商店发布需要维护者配置自己的正式签名。

## 验证边界

仓库包含 Android 工程、内置模型和测试。构建、逻辑单元测试、静态检查以及桌面模型推理与手机实际使用是不同证据层级。具体结果见[验证记录](docs/VALIDATION.md)。

2026-10-20 已在 HONOR DVD-AN80（Android 16 / API 36）安装并取得真实相机画面。4 个设备测试方法分两次执行通过，覆盖七个内置模型的 Android CPU 推理、真实 CameraX 推理与暂停恢复、设置持久化、前后镜头切换、暂停 Activity 重建及 CREATED → RESUMED 生命周期恢复。七模型检查包含在其中一个测试方法内，不另外计为 7 个 JUnit 测试。

已观察中文框与标签、可滚动设置和带框 JPEG 的系统分享预览，没有对外发送。实拍正确识别了笔记本电脑，也出现黄色异形物被判为“蛋糕”或“剪刀”的误判。深度图已显示，但没有真值精度验证；单张性能截图的 24.9 FPS / 35 ms 不是持续性能基准。

实际 GPU 后端、长期发热耗电、多机型兼容性尚未确认。生命周期重建通过不替代真实横屏视觉适配、锁屏解锁或前置镜像对齐验收，详见 `docs/DEVICE_CHECKLIST.md`。

设备测试使用真实相机，并在 `finally` 恢复原偏好。仓库保留文本测试结果，不包含测试者的相机现场照片、调试配对信息或本机环境文件。
